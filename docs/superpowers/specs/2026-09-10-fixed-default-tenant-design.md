# 默认租户与权限切换设计

## 目标

管理台登录成功后直接进入业务页面，不再展示租户选择页。超级管理员默认进入租户 `1`，并可在右上角切换目标租户；系统管理员只能使用账号所属租户。

## 设计

- 角色权限按集合判断，只要有效角色中包含 `KNOWLEDGE_SUPER_ADMIN`，就按超级管理员授权。
- 租户 Store 作为唯一租户上下文来源：超级管理员默认租户 ID `1`，系统管理员使用身份中的 `tenantId`。
- 管理布局不恢复 `TenantGate`，登录后直接渲染当前路由页面。
- 超级管理员可点击右上角“切换”按钮展开租户下拉菜单；系统管理员看到不可点击的所属租户标识。
- 当前可选租户只有租户 `1`“享佳健康”，不允许手工输入任意租户 ID。
- 现有接口继续从 `useTenantId()` 读取当前租户；切换后各页面监听租户变化并重新加载数据。

## 验收标准

- 登录后不会出现“请选择目标租户”。
- 同时拥有系统管理员和超级管理员角色的账号按超级管理员授权。
- 超级管理员默认显示“享佳健康”，点击“切换”后在按钮下方展开仅含“享佳健康”的下拉菜单。
- 系统管理员不能切换，所有管理接口只能使用其所属租户 ID。
