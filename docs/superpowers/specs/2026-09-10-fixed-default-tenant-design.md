# 固定默认租户设计

## 目标

管理台登录成功后直接进入业务页面，不再展示租户选择页。当前应用的所有知识库管理操作固定使用租户 `1`，顶部右侧显示租户名称“享佳健康”。

## 设计

- 租户 Store 作为唯一租户上下文来源，固定提供租户 ID `1` 和名称“享佳健康”。
- 普通管理员与超级管理员采用相同的租户上下文，不允许在前端切换租户。
- 管理布局移除 `TenantGate` 和租户切换交互，直接渲染当前路由页面。
- 顶部右侧使用不可点击的租户标识展示“享佳健康”。
- 现有接口继续从 `useTenantId()` 读取租户 ID，因此无需逐个修改接口调用。

## 验收标准

- 登录后不会出现“请选择目标租户”。
- 超级管理员登录后也直接进入管理台。
- 右上角显示“享佳健康”，且没有“切换”入口。
- 所有管理接口路径中的租户 ID 为 `1`。
